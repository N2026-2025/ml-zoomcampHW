## Methodology (summary)

1. **Preparation:** categoricals → `'NA'`, numericals → `0.0`.
2. **Exact split** from the statement → 3000 train / 1000 val / 1000 test.
3. **Q1:** use each numerical column as score on train (`roc_auc_score`), negate when AUC < 0.5 → `lead_score` wins (0.7882).
4. **Q2:** one-hot (`DictVectorizer`) + `LogisticRegression(liblinear, C=1.0)` → AUC 0.732 on validation.
5. **Q3:** sweep thresholds 0.0–1.0 (step 0.01), compute precision/recall, plot both → intersection at 0.63.
6. **Q4:** F1 = 2·P·R/(P+R) per threshold, plot → maximum at 0.41 (F1 ≈ 0.758).
7. **Q5:** `KFold(n_splits=5, shuffle=True, random_state=1)` on `df_full_train` → std ≈ 0.007.
8. **Q6:** same CV for `C ∈ [0.000001, 0.001, 1]` → best mean AUC 0.749 with C=0.001.
9. **Self-check:** final asserts cell validates every answer.

Compatibility note: with recent scikit-learn/scipy, `DictVectorizer` produces sparse matrices with int64 indices that `liblinear` rejects, so the notebook converts to dense with `.toarray()` (tiny data, identical results).

## Key learnings

- **ROC AUC as feature importance** ranks single variables by their ranking power; a score below 0.5 just means the correlation points the other way.
- **Precision vs recall** trade off as the threshold moves; their crossing point balances false positives and false negatives.
- **F1** summarizes that trade-off in one number — its peak (0.41) is a reasonable operating threshold here.
- **Cross-validation** quantifies score stability (std ≈ 0.007) before trusting a tuning decision.
- In sklearn, **small `C` = stronger regularization**: C=0.000001 underfits (0.617), C=0.001 is the sweet spot (0.749), C=1.0 overfits slightly (0.732).
